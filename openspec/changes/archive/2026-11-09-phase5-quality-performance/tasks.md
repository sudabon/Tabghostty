## 3. 大量出力（spec: terminal-rendering）

- [x] 3.1 受信時のデコードをバックグラウンドで行う処理、`TerminalController` での 64 KiB ずつの書き込みと `Task.yield()`、RenderState の更新を tick ごとに 1 回にまとめる処理、入力の経路を出力の処理から独立させる処理を実装する。大きな書き込みを処理している途中に送った入力が、書き込みの完了を待たずに送信されることをテストで確認する

- [x] 3.2 入力遅延を計測できるビルド（keyDown から画面に反映されるまでの時間をログに出す）を用意する。50 MB の `cat` を流している間の 95 パーセンタイルが 100 ms 以内であること、Ctrl+C で止められることを確認する（要手動確認）。結果は `docs/performance.md` に記録する
