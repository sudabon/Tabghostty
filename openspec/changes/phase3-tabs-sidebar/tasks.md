# Tasks

> 前提: `phase2-terminal-input` が完了し、archive 済みであること。

## 1. 全タブ attach（spec: terminal-session）

- [ ] 1.1 `SessionStore` に、`sessions` との差分でコントローラを作成・破棄する処理を追加する。増えた sid は attach し、消えた sid は破棄する。モック WS で「セッションが増えると attach が送られる」「消えるとコントローラが破棄される」ことをテストで確認する
- [ ] 1.2 `TerminalView` が表示するコントローラを切り替えられるようにする。IME の未確定文字列、選択範囲、viewport の位置はコントローラ側に移す。裏のタブの出力が切り替えた直後に replay なしで出ること（attach の送信が増えないこと）をモック WS のテストで確認する
- [ ] 1.3 グリッドサイズの変更を、live の全セッションに反映して `resize` を送る処理と、アクティブにしたときにサイズを送り直す処理を実装する。3 セッションでのリサイズとタブの切り替えで、送信されるフレームをテストで確認する

## 2. REST の拡張（spec: tab-operations）

## 5. タブ操作（spec: tab-operations）

- [ ] 5.1 選択（未読を消し、フォーカスを移す）、新規作成（Cmd+N と「＋ 新規タブ」）、複製、再起動（終了済みのときだけ）を実装する。どの操作でも、返ってきたセッションがアクティブになることを、モックを使ってテストで確認する
- [ ] 5.2 閉じる処理（`confirm_close_running` が有効で実行中なら確認シートを出す）と、`quit_when_no_tabs` を実装する。「1 件以上 → 0 件」になったら終了し、無効の設定なら「すべてのタブを閉じました」の画面を出す。どちらにするかの判定をテストで確認する。最後のタブを閉じるとアプリは終了し、デーモンは残ることを確認する（要手動確認）
- [ ] 5.3 ドラッグでの並べ替えを実装する（6pt 動いたらドラッグとみなし、`PUT /api/sessions/order` を送る。ローカルの並びは変えない）。ブラウザ版にも同じ順序が出ることを確認する（要手動確認）
- [ ] 5.4 メモの編集シートを実装する（30 code point に収める、変換中は収めない、Enter で保存、Escape で取り消し、前後の空白を削る、空なら消す、失敗したら開いたままにする）。収める処理と前後の空白の削除をテストで確認する
- [ ] 5.5 右クリックメニュー（複製 / 再起動 / 閉じる / 通知）と、通知ミュートの切り替え（楽観的に更新し、失敗したら戻してトーストを出す）を実装する。ミュートの切り替えが成功するケースと失敗するケースをテストで確認する
