- [ ] 2.3 `CellBuffers`（dirty の行だけ更新）と、背景、グリフ、装飾（下線、打ち消し線、カーソル、選択、IME の未確定文字列、検索の強調）のパイプラインを実装する。`ls --color`、`vim`、`htop`、CJK と絵文字のサンプルを、Core Text と Metal でスクリーンショットに撮って比べ、差がアンチエイリアス程度であることを確認する（要手動確認）
- [ ] 2.4 displayLink による vsync への同期、dirty が無いときの省略と pause、カーソルの点滅を点灯と消灯の切り替え時だけ dirty にすること、ウィンドウが隠れているときに描画を止めることを実装する。10 タブで 1 分間何もしないときの平均 CPU 使用率が 1% 未満であることを確認する（要手動確認）

## 3. 大量出力（spec: terminal-rendering）

- [ ] 3.1 受信時のデコードをバックグラウンドで行う処理、`TerminalController` での 64 KiB ずつの書き込みと `Task.yield()`、RenderState の更新を tick ごとに 1 回にまとめる処理、入力の経路を出力の処理から独立させる処理を実装する。大きな書き込みを処理している途中に送った入力が、書き込みの完了を待たずに送信されることをテストで確認する
